接入概览

外部站点通过本系统的码支付网关创建支付订单，用户扫码付款后，系统自动查询支付宝账单并回调商户。协议与主流码支付网关兼容。

所有接口均为 POST 或 GET 到 /api/codepay，通过 act 参数区分操作。 同时兼容旧系统常用的 /submit.php 与 /api.php 路径。

对接配置清单

本项目与彩虹易支付等主流码支付网关的接入方式一致。开始对接前，请按下表完成双方配置。

本系统（收款端）

  • 「支付配置」填写 AppId、应用私钥、支付宝公钥；
  • 转账链接模式填写收款账号 userId；经营码模式上传收款二维码；
  • 点击「自动生成商户凭据」并保存 pid / key，提供给对接方；
  • 支付宝开放平台开通「账户账单查询」权限，保持监控运行；
  • 服务器出网正常（用于查询支付宝账单与发送回调）。

对接方（商户站点）

  • 配置本系统接入地址（Base URL）；
  • 配置本系统生成的商户 ID（pid）与商户密钥（key）；
  • 提供公网可达的 notify_url（POST 表单，返回 success）；
  • return_url 可选，用于支付完成后跳转；
  • 按签名规则生成 sign，创建支付时传 type=alipay、订单号、名称、金额。

上线检查

  • 后台「概览」显示支付配置为「可下单」；「健康检查」payment_ready 为 true。
  • 用「在线调试」创建一笔最小金额订单，确认二维码/支付页正常。
  • 完成一笔真实小额支付，确认订单自动变为已支付，且对接方收到回调。
  • 回调返回非 success 时，后台订单列表会显示「待重试」，并按 1/5/15/30/60 分钟重试。
  • 回调参数、签名规则与常见码支付平台一致（trade_status=TRADE_SUCCESS，sign_type=MD5）。

快捷检查：GET /health；兼容路径：/submit.php、/api.php。

签名与认证

除 query 类查询外，创建支付与支付通知都需要 MD5 签名：

  • 收集本次请求的全部业务参数；
  • 过滤空值，并按参数名 ASCII 升序排序；
  • 拼接为 k1=v1&k2=v2；
  • 末尾拼接商户密钥，取 MD5 小写，作为 sign；
  • sign / sign_type / act / action / format 不参与签名。
import hashlib

def generate_sign(params: dict, merchant_key: str) -> str:
    ignored = {"sign", "sign_type", "act", "action", "format"}
    filtered = {k: v for k, v in params.items()
                if k not in ignored and v is not None and str(v) != ""}
    raw = "&".join(f"{k}={filtered[k]}" for k in sorted(filtered))
    return hashlib.md5((raw + merchant_key).encode("utf-8")).hexdigest()

响应约定

成功返回 {"code": 1, "msg": "SUCCESS"}；失败返回 {"code": -1, "msg": "原因"}。创建支付成功时额外返回 trade_no（平台订单号）、payment_amount（实际需支付金额）与 qr_code（二维码 base64）。

POST 支付通知（商户回调）

用户支付成功后，系统向商户的 notify_url 发送通知。商户需校验 sign，返回纯文本 success 表示已收到。

字段说明
pid商户 ID
trade_no平台订单号
out_trade_no商户订单号
type支付类型（alipay）
name商品名称
money订单金额
trade_status固定 TRADE_SUCCESS
sign / sign_typeMD5 签名，sign_type=MD5

重试机制

  • 商户返回 success（小写）即视为成功；其他内容或非 2xx 视为失败。
  • 失败自动重试，间隔依次为 1 分钟、5 分钟、15 分钟、30 分钟、60 分钟，最多 5 次。
  • 后台「码支付订单」列表显示回调状态（未回调 / 已回调 / 待重试 / 无需回调 / 回调失败），可对单笔订单手动「重发回调」。
  • 同一订单可能重复通知，请务必幂等处理（以 out_trade_no 为准）。

回调格式与彩虹易支付等主流码支付网关一致：POST 表单、MD5 签名、返回 success。

GET 健康检查

GET/health

返回依赖、配置、数据库与收款就绪状态，可用于监控探测。

快速接入（Python）

import hashlib
import requests

BASE = "{{ base_url }}"
PID = "{{ merchant_id or '你的商户ID' }}"
KEY = "{{ merchant_key or '你的商户密钥' }}"

params = {
    "pid": PID,
    "type": "alipay",
    "out_trade_no": "ORDER20260101001",
    "name": "测试商品",
    "money": "1.00",
    "notify_url": "https://your-site.com/pay/notify",
}

# 生成签名（排除 sign/sign_type/act/action/format）
raw = "&".join(f"{k}={params[k]}" for k in sorted(params) if str(params[k]) != "")
params["sign"] = hashlib.md5((raw + KEY).encode()).hexdigest()

# 创建支付
resp = requests.post(BASE + "/api/codepay", data={**params, "act": "submit", "format": "json"}).json()
print(resp)

# 展示二维码：resp["qr_code"] 为 PNG base64，前端拼成 data URI 即可显示

# 轮询订单状态
r = requests.get(BASE + "/api/codepay/status/" + params["out_trade_no"]).json()
print(r["status"])  # 0 待支付 1 已支付 2 已过期

回调验签示例（Flask）

import hashlib
from flask import Flask, request

app = Flask(__name__)
MERCHANT_KEY = "{{ merchant_key or '你的商户密钥' }}"

def verify_sign(params: dict) -> bool:
    received = params.get("sign", "")
    ignored = {"sign", "sign_type", "act", "action", "format"}
    filtered = {k: v for k, v in params.items() if k not in ignored and str(v) != ""}
    raw = "&".join(f"{k}={filtered[k]}" for k in sorted(filtered))
    return received == hashlib.md5((raw + MERCHANT_KEY).encode()).hexdigest()

@app.post("/pay/notify")
def notify():
    params = request.form.to_dict() or request.args.to_dict()
    if not verify_sign(params):

    return "success"
